# Careem — portfolio landing page

A responsive static portfolio concept built with HTML and CSS. Includes selected work, an about section, and an email contact link. All project artwork is drawn in CSS; no image assets or build dependencies are required.

## Run locally

Open `index.html` in your browser, or run from this directory:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000` on your own computer.

Edit the name, copy, sample project concepts, and `hello@example.com` contact address in `index.html`. Adjust the colors and layout in `styles.css`. Google Fonts are optional; system fonts are used when offline.

The featured video lives in `assets/portfolio-video.mp4`, with playback controls, inline mobile playback, and a cover image. It was converted from the uploaded MOV for browser compatibility.

## Publish with GitHub Pages

In the GitHub repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/ (root)**, then **Save**. Once GitHub finishes deployment, the site will be at `https://careem0625.github.io/Portfolio-Draft/`.
